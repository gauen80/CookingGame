## 1. **게임 콘셉트와 목표 설정**

**게임 장르:** 3D 싱글요리 게임 (멀티도 고려 중)

**플랫폼:** PC/콘솔

**게임 콘셉트:** 플레이어가 제한된 시간 내에 주어진 요리를 완성해야 함.
**게임 목표:** 제한 시간 동안 최대한 많은 요리를 정확하게 서빙하여 높은 점수와 별(Star) 등급을 획득하는 것.

## 2. **스토리라인 설정**

**배경** : 구상 중

## **3. 주요 시스템**

### **쿠킹 시스템**

- **재료 조합 및 조리**
    - ScriptableObject를 활용하여 레시피 데이터베이스 구축
    - 재료 상태 변화: 날것(Raw) -> 썰린 상태(Sliced) -> 익힌 상태(Cooked) -> 탄 상태(Burned).

- **카운터 상호작용시스템**
    - ClearCounter
    - CuttingCounter
    - StoveCounter
    


## 4. **기능 구현 계획**

플레이어 캐릭터의 상태를 '빈손 상태(EmptyHanded)'와 '물건을 든 상태(HoldingObject)' 두 가지로 정의하겠습니다.

### 1. 플레이어 이동 및 상태 구현
- **빈손상태**
   - container counter와 E키로 상호작용 시, 재료 객체(KitchenObject)를 생성하여 플레이어의 손 위치(Hold Point)로 부모를 설정하고 이동.
   - 바닥에 떨어진 재료를 Raycast로 감지하여 줍기 가능

- **물건을 든 상태**
   - 빈 카운터(ClearCounter)를 향해 E키를 누르면 손에 든 물건을 카운터로 이전.
   - 상호작용 카운터에서 q키 연타시 재료 조리.
   - 다른 재료나 접시가 있을 경우 상호작용하여 요리 조합
